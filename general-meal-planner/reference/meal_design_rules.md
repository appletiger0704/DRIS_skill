# Meal design rules

## 午餐與晚餐結構

午餐與晚餐不可只寫一個總菜名。每餐必須包含：

- 1 份主食
- 1 份主菜或主餐
- 3 份副菜

## `計算!A` 餐別代碼

餐別文字必須使用 DRIS 範本原始代碼：

- `1早餐`
- `2午餐`
- `3晚餐`
- `4早點`
- `5午點`
- `6晚點`
- `7流灌`

不可寫成 `2午餐-主食` 或 `3晚餐-副菜1`，否則公式可能抓不到資料。

## 排序

主餐顯示順序必須是：

```text
1早餐 → 2午餐 → 3晚餐
```

若有點心，排序優先權為：

```text
1早餐 = 10
4早點 = 20
2午餐 = 30
5午點 = 40
3晚餐 = 50
6晚點 = 60
7流灌 = 70
```

午餐與晚餐內部排序：

```text
主食 → 主菜/主餐 → 副菜1 → 副菜2 → 副菜3 → 調味料或補充食材
```

## 低鈉增味

慢性病菜單不可為了低鈉而完全無味。可使用蒜、薑、蔥、洋蔥、九層塔、洋香菜、迷迭香、米醋、檸檬汁、胡椒、五香粉、咖哩粉、少量芝麻油或香油提高風味。
