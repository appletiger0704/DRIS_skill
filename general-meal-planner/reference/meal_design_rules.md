# Meal design rules

## 午餐與晚餐結構

午餐與晚餐不可只寫一個總菜名。每餐必須包含：

- 1 份主食
- 1 份主菜或主餐
- 3 份副菜

## `計算!A` 餐別代碼

餐別文字必須使用 DRIS 範本原始代碼：

- `1早餐`
- `2午餐`
- `3晚餐`
- `4早點`
- `5午點`
- `6晚點`
- `7流灌`

不可寫成 `2午餐-主食` 或 `3晚餐-副菜1`，否則公式可能抓不到資料。

## 排序

主餐顯示順序必須是：

```text
1早餐 → 2午餐 → 3晚餐
```

若有點心，排序優先權為：

```text
1早餐 = 10
4早點 = 20
2午餐 = 30
5午點 = 40
3晚餐 = 50
6晚點 = 60
7流灌 = 70
```

午餐與晚餐內部排序：

```text
主食 → 主菜/主餐 → 副菜1 → 副菜2 → 副菜3 → 調味料或補充食材
```

## 低鈉增味

慢性病菜單不可為了低鈉而完全無味。可使用蒜、薑、蔥、洋蔥、九層塔、洋香菜、迷迭香、米醋、檸檬汁、胡椒、五香粉、咖哩粉、少量芝麻油或香油提高風味。


## v5 補充：調味料與微量營養素

- 除甜點或單純水果外，每道主食、主菜、副菜至少要有 2 種低鈉增味元素。
- 調味料不是只寫在作法裡；若用於營養補強，需列為食材並寫重量。
- 低鈉又可補微量營養素的常用元素：洋香菜片、迷迭香粉、白胡椒粉、咖哩粉、五香粉、黑芝麻粉、檸檬汁、米醋、大蒜、薑、蔥。
- CKD 高血鉀時，使用香草粉與調味粉也必須小量並計算鉀、磷。


## v6 補充：每道菜 2+3 結構

- 每道菜盡量至少包含 2 種主要食材。主要食材可包含主食、蔬菜、水果、蛋白質食材、低氮澱粉、菇藻類等。
- 油、糖、醋、胡椒粉、香草粉、辛香料粉、鹽味醬料不算主要食材。
- 每道菜盡量至少包含 3 種調味料或低鈉增味元素，例如蒜、薑、蔥、洋蔥、九層塔、洋香菜、迷迭香、羅勒、米醋、檸檬汁、白胡椒、黑胡椒、五香粉、咖哩粉、肉桂粉、少量香油。
- CKD 高血鉀菜單中，所有香草粉、辛香料粉也需列入食材明細並計算重量，避免隱藏鉀與磷。
- 如因治療限制無法達成，需在菜單 JSON 內加入 `quality_exemption`，說明不能達成原因。
