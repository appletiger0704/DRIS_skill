# 料理多樣性與口味設計規則

## 核心原則

菜單不能只追求營養數字，也要能被一般人接受。每道料理需要兼顧風味、口感、顏色、烹調可行性與疾病限制。

## 每道料理至少 5 種元素

每道料理至少包含 5 種以上「食材或調味元素」。例如：

- 雞胸肉 + 洋蔥 + 甜椒 + 蒜末 + 檸檬汁 + 黑胡椒 + 橄欖油。
- 豆腐 + 香菇 + 青江菜 + 薑絲 + 醬油 + 芝麻油。
- 鮭魚 + 櫛瓜 + 番茄 + 洋蔥 + 檸檬 + 黑胡椒。

營養計算時：

- 油、糖、醬油、味噌、芝麻醬等需估算重量。
- 少量蒜、薑、胡椒、香草可只列於料理說明。
- 高血壓與 CKD 個案需特別估鈉。

## 烹調法多樣化

一日菜單至少使用 3 種不同料理法：

- 蒸、煎、炒、燉、烤、拌、氣炸、汆燙後快炒。
- CKD 或高血壓不建議大量湯品與滷汁。
- 糖尿病避免勾芡、糖醋、蜜汁等高糖烹調。
- 高血脂避免油炸與高飽和脂肪醬汁。

## 午餐與晚餐結構規則

標準固體餐菜單中，午餐與晚餐不可只列一個總菜名。每餐必須拆成：

- 1 份主食
- 1 份主餐/主菜
- 3 份副菜

副菜需盡量使用不同蔬菜或不同處理方式，例如「蒜香高麗菜、胡瓜炒木耳、涼拌小黃瓜」，不可三份都寫成「燙青菜」。若個案為 CKD 高血鉀，副菜仍可達 3 份，但每份重量需較小、需先汆燙去鉀並倒掉湯汁。

## 最終輸出格式

每道料理都要寫：

1. 食材與重量。
2. 調味料與用量。
3. 作法。
4. 疾病或運動提醒。

範例：

```text
彩椒雞丁
食材：雞胸肉 80g、甜椒 60g、洋蔥 30g、蒜末 3g、橄欖油 5g、黑胡椒少許、低鈉醬油 3g。
作法：雞胸肉切丁，用黑胡椒與少量低鈉醬油抓醃。鍋中加入橄欖油，先炒香蒜末與洋蔥，再加入雞丁炒至變色，最後放入甜椒快炒保留脆度。
提醒：適合高血壓者，但醬油不可再追加；若為 CKD 且血鉀高，甜椒可先汆燙後再炒。
```
