# Reference

此資料夾保存 `general-meal-planner` skill 的判斷依據與操作規則。它不是用來取代 `SKILL.md`，而是讓模型與本機腳本在處理正式 DRIS Excel、菜單設計、料理靈感查詢與疾病客製化時有一致的參照。

建議閱讀順序：

1. `dris_excel_structure.md`：正式 DRIS Excel 的 sheet、欄位與寫入位置。
2. `taiwan_dris_vitamin_targets.md`：台灣第八版 DRIs 維生素目標欄位與 Excel 填寫規則。
3. `meal_design_rules.md`：菜單結構、餐別排序與料理描述規則。
4. `cooking_variety_guidelines.md`：料理多樣性、口味設計與調味元素規則。
5. `general_condition_nutrition.md`：泛用疾病分類與運動營養設定邏輯。
6. `ckd_non_dialysis_rules.md`：CKD 未透析個案的營養控制重點。
7. `recipe_sources.md`：TasteAtlas、Gastronomixs、The World's 50 Best Restaurants 的查詢用途。
8. `troubleshooting.md`：Excel 損毀、公式未更新、食材查不到等處理方式。
